# MBD-GI
Implements [Moving Basis Decomposition](https://research.activision.com/publications/2021/09/moving-basis-decomposition-for-precomputed-light-transport)
in a global-illumination context with spherical harmonics.

Still a Work-In-Progress, but the core optimization algorithm is in place and functional.

### External Libraries
This libraries are included in the external/ folder:  
-GLAD
-IMGUI
-tinyobjloader

This program also depends on:  
-GLFW
